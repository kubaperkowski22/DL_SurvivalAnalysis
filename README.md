# DL_SurvivalAnalysis

Głębokie sieci neuronowe w analizie przeżycia

Element badawczy: Opracowanie własnego lub modyfikacja istniejącego modelu głębokiej sieci neuronowej oraz porównanie jego skuteczności z klasycznymi metodami analizy danych przeżycia.

-Wprowadzenie do analizy przeżycia.
-Wprowadzenie do uczenia głębokiego.
-Przegląd literatury dotyczącej wykorzystania modeli głębokich w analizie przeżycia.
-Implementacja wybranego modelu głębokiej sieci neuronowej do analizy danych przeżycia.
-Eksperymentalna weryfikacja zaproponowanego modelu oraz porównanie jego działania z istniejącymi metodami analizy przeżycia.
-Analiza i interpretacja uzyskanych wyników.

Implementacja modeli DeepSurv oraz DeepHit. Dodatkowo stworzono moduły oceniania ważności cech w tych modelach. Nowopowstałe modele nazwano DeepSurvAtencjusz oraz DeepHitAtencjusz.

Badania są prowadzone na 7 zbiorach danych z amerykańskiego National Cancer Institute. Zbiory danych dotyczą raka mózgu, raka piersi, raka prostaty, raka płuc, raka jelita cienkiego, chłoniaka oraz białaczki. Liczba rekordów wynosi od około 20.000 do około 700.000.
